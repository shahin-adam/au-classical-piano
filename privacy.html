This policy covers AU Classical Piano Uploader ("the tool"), a private publishing tool operated by the owner of the AU Classical Piano and Bersivey YouTube channels.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses the tool

Only the channel owner signs in, with their own Google account through Google OAuth. The tool is not offered to the public and has no other users.

What data the tool accesses

  • The owner's own channel identity (channel ID and title), to confirm uploads go to the correct channel.
  • The owner's own videos and playlists: titles, descriptions, thumbnails, privacy and processing status, and playlist items, to upload videos and verify them.

The tool does not access other users' data, comments, subscribers or analytics, and does not display YouTube content to anyone.

How data is used, stored and shared

  • Data is used only to publish and verify the owner's own videos.
  • Upload receipts (video IDs, titles, timestamps, status) are kept on the owner's private storage as a publishing record. No other API data is stored.
  • OAuth tokens are stored only on the owner's private computer and are never shared.
  • No data is sold, shared with or disclosed to third parties.
  • The tool uses no cookies, tracking or advertising.

Revoking access

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. Stored receipts can be deleted on request.

Contact

Questions about this policy can be raised through the issues page of this site's repository.
